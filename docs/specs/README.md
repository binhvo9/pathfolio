# Feature Specs

One MD file per feature. This is where a feature gets designed in detail
before/while it's built — not just a backlog line item.

## Workflow

1. Feature shows up in [BACKLOG.md](../../BACKLOG.md).
2. Before building it, write a spec here: `NN-feature-name.md`
   (`NN` = incrementing number, so reading order = build order).
3. Build against the spec. If reality diverges, update the spec — it should
   describe the feature as it actually works, not just as planned.
4. Mark it done in [FEATURES.md](../../FEATURES.md) (append to the bottom
   of the Completed list).

## Naming

`NN-feature-name.md`, e.g. `01-onboarding-interview.md`,
`02-risk-score-calculation.md`.

## Template

Copy [TEMPLATE.md](TEMPLATE.md) for each new spec.
